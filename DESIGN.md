# Norse Kode — Interface World

## Visual direction

Norse Kode is presented as a dark, compact tabletop instrument: blackened timber and iron lines frame warm ivory playing cards, with signal-red oath marks and amber state accents. The interface is deliberately closer to a card table and playtest notebook than to a collectible-card-game battlefield.

## Composition

The first viewport leads with the game's memorable truth — “The lines are known. The order is not.” — then puts phase, War score, and the current decision surface in one scan. The active play surface is a working board, not a decorative hero. The combat log and edge-case notebook stay adjacent so unusual results are captured without leaving the clash.

## Type and color

Large serif display type carries saga weight; compact sans labels carry controls and instrumentation. The palette is restrained: deep brown-black surfaces, ivory card faces, Norse red for commitment and disruption, amber for measurements and phase cues, and muted blue/violet/green for suit and hero distinctions.

## Interaction language

Play mode protects the opponent's uncommitted or locked formation during pass-and-play. Debug mode reveals both formations and calculations. The engine stops revealing cards as soon as a Skirmish is won; every action that changes state adds a plain-language event to the combat log.

## Responsive behavior

The desktop layout keeps the log beside the main board. At tablet widths the log becomes a full-width column. At mobile widths the game remains a single scrollable working surface, with five-card lines compressed but readable and clash entries stacked.
